# Конфигурационное управление · ДЗ № 3 · Вариант 12

Проект для сборки и выполнения программ учебной виртуальной машины (УВМ).
Ассемблер преобразует исходный текст в список инструкций, затем кодирует
их поля и записывает машинный код в двоичный файл.

## Язык ассемблера

Одна строка содержит одну инструкцию. Операнды разделяются запятыми,
регистр мнемоник не важен. Пустые строки и текст после `#` пропускаются.
Числа задаются в десятичном виде или с префиксом `0x`.
Адреса и константы занимают 32 бита, смещение занимает 8 бит.
Все операнды задаются как беззнаковые целые.

Поля в синтаксисе соответствуют именам из спецификации. `M[x]` обозначает
ячейку памяти с адресом `x`.

| Инструкция | Код A | Действие УВМ |
| --- | ---: | --- |
| `LOAD B, C` | 18 | Записать константу `C` в `M[B]`. |
| `READ B, C, D` | 9 | Скопировать `M[M[B] + C]` в `M[D]`. |
| `STORE B, C` | 10 | Скопировать `M[C]` в `M[M[B]]`. |
| `ADD B, C, D` | 13 | Записать сумму `M[C] + M[M[D]]` в `M[B]`. |

## Машинный код

Поле `A` занимает младшие 5 бит. Следующие поля размещаются подряд с учётом
их разрядности. Младший байт записывается первым (little-endian), неиспользуемые
старшие биты последнего байта равны нулю. В файле команды следуют друг за другом.

| Инструкция | Поля | Размер в байтах |
| --- | --- | ---: |
| `LOAD` | A 0–4, B 5–36, C 37–68 | 9 |
| `READ` | A 0–4, B 5–36, C 37–44, D 45–76 | 10 |
| `STORE` | A 0–4, B 5–36, C 37–68 | 9 |
| `ADD` | A 0–4, B 5–36, C 37–68, D 69–100 | 13 |

## Запуск и тесты

Нужны Python 3.10 или новее и оболочка `sh`. Сборка и установка пакетов
не требуются.

```sh
./run.sh SOURCE OUTPUT [--test]
```

- `SOURCE` задаёт путь к текстовому файлу UTF-8.
- `OUTPUT` задаёт путь к двоичному файлу с машинным кодом.
- `--test` дополнительно выводит байты каждой команды в формате спецификации.

После записи файла ассемблер выводит число команд. При ошибке разбора
он выводит номер строки и возвращает ненулевой код завершения.

```sh
./run.sh tests/fixtures/spec.asm example.bin --test
python3 -m unittest discover -s tests -v
```

Ожидаемый вывод для `spec.asm`

```text

0x12, 0x3A, 0x00, 0x00, 0xA0, 0x5F, 0x00, 0x00, 0x00
0x69, 0x3A, 0x00, 0x00, 0xE0, 0x5C, 0x3C, 0x00, 0x00, 0x00

0x8D, 0x2B, 0x00, 0x00, 0xE0, 0x03, 0x00, 0x00, 0xC0, 0x22, 0x00, 0x00, 0x00
```

## Функции ассемблера

- `parse_operand` разбирает число и проверяет, что оно помещается в поле.
- `parse_instruction` проверяет мнемонику и операнды, возвращает инструкцию.
- `parse_program` разбирает исходник и добавляет номер строки к ошибкам.
- `Instruction.format_fields` форматирует поля промежуточного представления.
- `encode_instruction` упаковывает поля команды в машинный код.
- `format_bytes` форматирует байты команды для вывода в тестовом режиме.
- `main` обрабатывает параметры CLI, записывает файл и выводит результат.
